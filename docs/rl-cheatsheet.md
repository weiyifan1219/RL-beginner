# 强化学习速查表

| 概念 | 公式/定义 | 直觉 |
|---|---|---|
| 回报 | `G_t = Σ γ^k R_{t+k+1}` | 从当前开始未来奖励的折扣和 |
| 状态价值 | `V^π(s)=E_π[G_t\|S_t=s]` | 在状态 s 按策略 π 能有多好 |
| 动作价值 | `Q^π(s,a)=E_π[G_t\|S_t=s,A_t=a]` | 在 s 做 a 后能有多好 |
| Bellman optimality | `Q*(s,a)=E[r+γ max_a'Q*(s',a')]` | 最优时下一步总选最优动作 |
| TD error | `δ_t=r+γV(s')-V(s)` | 当前估计和 bootstrap 目标的差 |
| 策略梯度 | `∇J=E[∇log π(a\|s) A(s,a)]` | 增加正优势动作的概率 |
| GAE | `Â_t=Σ(γλ)^l δ_{t+l}` | 用 λ 平衡 bias 与方差 |
| PPO | `min(r_tÂ_t, clip(r_t,1-ε,1+ε)Â_t)` | 限制单次策略变化 |
| SAC | `max E[Σr + αH(π)]` | 高奖励与高探索熵并存 |
