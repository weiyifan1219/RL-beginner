# 任务一：多臂老虎机与探索

> 主路线见仓库根 [README](../README.md)。本任务是一个可逐步填充的学习单元：先推导，再在 `src/` 中手写，再用实验解释现象，最后才对照成熟框架。

## 一句话目标

在无状态的 k 臂老虎机中推导并实现增量价值估计，比较 ε-greedy、UCB 与 Thompson Sampling 对累积遗憾的影响。

## 核心概念

探索/利用；期望奖励；regret；置信上界；后验采样

## 本任务交付

手写 `BanditEnv`、三种策略和统一实验循环；在固定种子下画平均回报与累计 regret 曲线。

## Definition of Done

- [ ] M1：实现 sample-average 与 constant-step-size 更新
- [ ] M2：实现 ε-greedy
- [ ] M3：实现 UCB 或 Thompson
- [ ] M4：比较至少 3 个探索强度。

## 建议步骤

1. 在 `notes/` 手写或整理关键公式，标明每一个期望来自何处。
2. 先创建最小的、可复现的环境与随机种子，完成 `src/` 的朴素实现。
3. 增加训练循环和评测循环，输出曲线到 `figures/`、指标到 `notes/`。
4. 做至少一个只改动一个变量的对照实验，并解释结果。
5. 最后阅读对应框架实现或 Stable-Baselines3 / TRL 文档，对照而不替代手写版本。

## 前置知识

无；仅 NumPy 和 Matplotlib。

## 实现边界与常见提醒

先写解析/模拟环境，再写策略；不要调用现成 bandit 库。
