# 任务一：多臂老虎机代码 Review 提示词

请对照本任务 README 和 `tests/` 审查我的实现。按以下顺序检查：

1. 样本平均是否在递增 count 后使用 `1/count`，固定步长是否真的不随 count 变化。
2. ε-greedy 利用时是否随机打破最大值并列，探索时是否在全部动作均匀采样。
3. UCB 是否处理未访问动作，公式是否为 `Q + c*sqrt(log(t)/N)`。
4. Thompson 是否明确限定 Beta-Bernoulli，并拒绝非 0/1 奖励。
5. regret 是否由期望奖励差计算，非平稳环境是否在 `pull` 前记录 gap。
6. 多 seed 实验是否每次创建新环境和新 agent，二者 RNG 是否独立且可复现。

不要直接重写全部代码。先给出最高优先级的一个可复现问题、触发它的最小输入、预期与实际结果，再给最小修复建议。
