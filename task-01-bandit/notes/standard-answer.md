# Task 01 标准答案讲义

## 1. 从估计问题开始

Bandit 没有状态，最小学习对象是每个动作的期望奖励 `q*(a)`。如果动作 `a` 已被选择 `n` 次，奖励为 `R_1,...,R_n`，最自然的估计是样本均值：

```text
Q_n(a) = (R_1 + ... + R_n) / n
```

将 `n+1` 个样本的均值展开：

```text
Q_{n+1}
= 1/(n+1) * (R_1 + ... + R_n + R_{n+1})
= 1/(n+1) * (n Q_n + R_{n+1})
= Q_n + 1/(n+1) * (R_{n+1} - Q_n)
```

这给出强化学习中反复出现的模板：

```text
NewEstimate = OldEstimate + StepSize * (Target - OldEstimate)
```

后续 TD、Q-Learning、Actor-Critic 的更新都会再次出现这个结构。

## 2. 为什么固定步长能追踪变化

样本平均中，第一个奖励在第 `n` 步仍有 `1/n` 权重；环境改变后，早期历史会拖慢适应。固定 `alpha` 的递推展开后，旧奖励权重按 `(1-alpha)^k` 指数衰减，所以形成 recency weighting。

代价是估计不会严格收敛到一个常数，而会围绕当前真实值波动。非平稳问题关心追踪速度，这通常正是需要的取舍。

## 3. 三种策略实际在做什么

### ε-greedy：固定探索预算

ε 不随证据变化。优点是机制简单、对奖励分布假设少；缺点是无论某个动作已经多差，都继续分到探索概率。ε 太小可能早早锁定错误动作；太大则长期浪费奖励。

### UCB：显式 optimism under uncertainty

经验均值是当前最好判断，bonus 是“这个动作也许比看上去更好”的上界。`N(a)` 增大时 bonus 缩小，说明证据变多；`log(t)` 增长使一个长期没访问的动作不会永久消失。

`c` 控制乐观程度：`c=0` 退化成 greedy；过大则长期过度探索。

### Thompson：按“成为最优的可能性”探索

Beta 后验不是一个点，而是一整个概率分布。每步对每个动作采一个可能的成功率，相当于从当前世界观中采样一个可能世界，然后在该世界里贪心。

这把探索与不确定性统一起来：后验宽时更可能采到极端高值；后验窄时动作选择趋于稳定。

## 4. 为什么要独立随机数流

如果环境和策略共享一个 RNG，给策略增加一次随机 tie-break 会消耗一个随机数，随后环境的所有奖励样本都会错位。此时两个算法看到的环境噪声不同，对比混入额外方差。

标准答案用 `SeedSequence(seed).spawn(2 * n_runs)` 给每次 run 的环境和 agent 分配不同 seed。这样：

- 同配置、同 seed 完全可复现；
- 策略内部随机调用次数不会改变环境 RNG；
- 每个 run 又彼此独立。

## 5. Regret 的选择

本任务记录：

```text
instant_regret_t = max_a q*_t(a) - q*_t(A_t)
```

它是基于期望差的 pseudo-regret，必定非负，因此累计曲线单调。它衡量“选错动作造成的期望机会成本”。

实际 reward 仍单独记录，用于观察学习者真实得到多少回报。二者回答不同问题，不能混在一起。

## 6. 代码设计决策

| 决策 | 原因 |
|---|---|
| 环境的 `expected_rewards` 返回副本 | 防止评测代码意外修改真实环境 |
| agent 暴露 `estimates/counts` | 教学时可直接画估计过程 |
| factories 接收 seed | 每个重复实验创建全新且可复现的对象 |
| dataclass 结果固定形状 | 输入输出契约清楚，Notebook/测试/CLI 共用 |
| Thompson 对非二元奖励报错 | 让模型假设显式化，不静默产出错误后验 |
| 非平稳环境在奖励后漂移 | 第 t 步 reward/regret 都对应同一个 `q_t` |

## 7. 默认实验应观察什么

默认环境成功率为 `[0.1, 0.3, 0.5, 0.7, 0.9]`。不要把某一次曲线的精确排名当结论；先观察：

1. 初期三者都不确定，曲线波动明显。
2. 最优动作率应随时间上升。
3. 累计 regret 应单调，但斜率会逐渐降低。
4. Thompson/UCB 通常比固定 ε 更少持续探索明显差的动作。

统计结论需要多 seed。单条轨迹适合解释机制，不适合宣布算法优劣。

## 8. 非平稳实验的参考解释

对随机游走 Gaussian bandit，同样使用 ε-greedy：

- sample-average 会让步长越来越小；训练越久，新奖励影响越弱；
- `alpha=0.1` 始终保留适应能力；
- 漂移非常小时样本平均仍可能表现不错，因为它方差更低；
- 漂移增大时固定步长通常更快追踪当前最优动作。

因此“固定步长一定更好”也不准确。结论依赖环境变化速度、奖励噪声和 alpha。

## 9. 练习参考答案

1. **纯 greedy 为什么可能失败？** 初始噪声可能让次优臂暂时领先；不再探索就永远没有证据纠正它。
2. **乐观初值为什么能探索？** 未访问动作保持高估值，已访问动作被真实奖励拉低，于是其他动作获得机会。
3. **UCB 与 Thompson 的共同点？** 都让证据少的动作拥有更高探索机会；一个用显式上界，一个从后验采样。
4. **为什么主实验选 Bernoulli？** 三种策略都适用，尤其可保证 Beta-Bernoulli Thompson 的概率模型正确。
5. **3090 有帮助吗？** Task 01 是小规模 NumPy CPU 实验，GPU 不会带来教学价值；后续 DQN 起才使用 PyTorch/GPU。
